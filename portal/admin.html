ผู้ดูแลระบบ

เครื่องมือและงานประจำของทีมแพลตฟอร์มข้อมูล หน้านี้เปิดได้เฉพาะบัญชีระดับทีมพัฒนาระบบ และแต่ละระบบยังตรวจสอบสิทธิ์ของตนเองทุกครั้ง

เครื่องมือของระบบ

เปิดได้จากเครื่องแม่ข่าย หรือผ่าน SSH tunnel ไปยังเครื่องแม่ข่ายเท่านั้น

หน้านี้ไม่ได้เปิดจากเครื่องแม่ข่าย ลิงก์เครื่องมือจึงถูกปิดไว้ โปรดเชื่อมต่อผ่าน SSH tunnel แล้วเปิดหน้านี้จาก localhost

จัดการท่อนำเข้าข้อมูลNiFi · ผู้ดูแลระบบเท่านั้น ติดตามคำสั่งวิเคราะห์Trino · ผู้ดูแลระบบเท่านั้น ตรวจสอบดัชนีค้นหาQdrant · ผู้ดูแลระบบเท่านั้น ตรวจสอบพื้นที่จัดเก็บRustFS · ห้ามแก้ไข metadata โดยตรง จัดการบัญชีและสิทธิ์ระบบรายงานSuperset · ผู้ดูแลระบบเท่านั้น

งานดูแลระบบที่ใช้บ่อย

เรียกใช้จากไดเรกทอรีของ repository บนเครื่องแม่ข่าย คำสั่ง SQL เรียกใช้ในฐานข้อมูล platform ด้วยบัญชีเจ้าของฐานข้อมูล

งานคำสั่ง
สร้างบัญชีผู้ใช้แบบอีเมลและรหัสผ่าน./scripts/create-password-account.sh <email> "<display name>"
มอบระดับสิทธิ์และหน่วยงานให้บัญชีUPDATE identity.app_user SET access_tier = '<tier>', org_unit = '<unit>' WHERE email = '<email>';
ปรับปรุงกลุ่มสิทธิ์ใน Trino หลังมอบหรือถอนสิทธิ์./scripts/publish-trino-groups.sh
ปรับปรุงบัญชีรายการชุดข้อมูลบนหน้าแรก./scripts/publish-portal-catalog.sh
ตรวจสอบบัญชีและสิทธิ์ของระบบ./scripts/verify-dev-accounts.sh

ระดับสิทธิ์ที่ใช้ได้: none, viewer, viewer_exec, analyst, steward และ developer โดย viewer และ steward ต้องระบุหน่วยงานเสมอ
