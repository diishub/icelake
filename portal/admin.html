ผู้ดูแลระบบ

จัดการบัญชีผู้ใช้ และเครื่องมือของทีมแพลตฟอร์มข้อมูล หน้านี้เปิดได้เฉพาะผู้ดูแลระบบและทีมพัฒนาระบบ และแต่ละระบบยังตรวจสอบสิทธิ์ของตนเองทุกครั้ง

บัญชีผู้ใช้และสิทธิ์

สร้างบัญชีแบบอีเมลและรหัสผ่าน มอบหรือถอนระดับสิทธิ์ และปิดบัญชี การเปลี่ยนแปลงมีผลกับ Trino ภายในไม่กี่วินาทีและถูกบันทึกทุกครั้ง

บัญชี ระดับสิทธิ์ หน่วยงาน สถานะ เข้าใช้ล่าสุด การจัดการ
กำลังโหลดข้อมูล…

ประวัติการเปลี่ยนแปลงบัญชี

50 รายการล่าสุด รายการที่ไม่มีชื่อผู้ดำเนินการทำจากเครื่องแม่ข่าย

เวลา ผู้ดำเนินการ รายการ บัญชี การเปลี่ยนแปลง

เครื่องมือของระบบ

เปิดได้จากเครื่องแม่ข่าย หรือผ่าน SSH tunnel ไปยังเครื่องแม่ข่ายเท่านั้น

หน้านี้ไม่ได้เปิดจากเครื่องแม่ข่าย ลิงก์เครื่องมือจึงถูกปิดไว้ โปรดเชื่อมต่อผ่าน SSH tunnel แล้วเปิดหน้านี้จาก localhost

จัดการท่อนำเข้าข้อมูลNiFi · ผู้ดูแลระบบเท่านั้น ติดตามคำสั่งวิเคราะห์Trino · ผู้ดูแลระบบเท่านั้น ตรวจสอบดัชนีค้นหาQdrant · ผู้ดูแลระบบเท่านั้น ตรวจสอบพื้นที่จัดเก็บRustFS · ห้ามแก้ไข metadata โดยตรง จัดการบัญชีและสิทธิ์ระบบรายงานSuperset · ผู้ดูแลระบบเท่านั้น

งานดูแลระบบที่ใช้บ่อย

เรียกใช้จากไดเรกทอรีของ repository บนเครื่องแม่ข่าย คำสั่ง SQL เรียกใช้ในฐานข้อมูล platform ด้วยบัญชีเจ้าของฐานข้อมูล

งานคำสั่ง
สร้างหรือรีเซ็ตรหัสผ่านของผู้ดูแลระบบ (admin)./scripts/create-admin-account.sh <email> "<display name>"
สร้างบัญชีผู้ใช้แบบอีเมลและรหัสผ่าน./scripts/create-password-account.sh <email> "<display name>"
มอบระดับสิทธิ์และหน่วยงานให้บัญชีUPDATE identity.app_user SET access_tier = '<tier>', org_unit = '<unit>' WHERE email = '<email>';
ปรับปรุงกลุ่มสิทธิ์ใน Trino ทันที (ปกติบริการ trino-groups-sync ทำให้อัตโนมัติ)./scripts/publish-trino-groups.sh
ปรับปรุงบัญชีรายการชุดข้อมูลบนหน้าแรก./scripts/publish-portal-catalog.sh
ตรวจสอบบัญชีและสิทธิ์ของระบบ./scripts/verify-dev-accounts.sh

ระดับสิทธิ์ที่ใช้ได้: none, viewer, viewer_exec, analyst, steward, admin และ developer โดย viewer และ steward ต้องระบุหน่วยงานเสมอ ผู้ดูแลระบบ (admin) มอบสิทธิ์ developer ไม่ได้

เพิ่มบัญชีผู้ใช้

บัญชีเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน แจ้งรหัสผ่านแก่เจ้าของบัญชีผ่านช่องทางที่หน่วยงานไว้วางใจ

เว้นว่างเพื่อใช้ส่วนหน้า @ ของอีเมล ใช้ได้เฉพาะ a-z 0-9 . _ - และเปลี่ยนภายหลังไม่ได้
