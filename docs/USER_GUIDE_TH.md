# คู่มือเริ่มใช้ PSU Data Hub ฉบับ 2 นาที

คู่มือนี้สำหรับผู้ใช้ Pilot ที่ต้องการดูรายงานหรือขอใช้ข้อมูล โดยไม่ต้องรู้จัก
เครื่องมือด้านเทคนิคของแพลตฟอร์ม

## เริ่มจากตรงไหน

1. เปิด <http://localhost:8085> หรือ URL ภายในที่ทีมแพลตฟอร์มแจ้ง
2. เลือกบทบาทที่ใกล้กับงานวันนี้ การเลือกนี้ใช้จัดคำแนะนำเท่านั้น ไม่เปลี่ยน
   สิทธิ์ข้อมูล
3. ถ้ายังไม่เคยใช้ ให้เปิด **ลองดูตัวอย่าง 2 นาที** ก่อน ตัวเลขในตัวอย่างเป็น
   ข้อมูลสมมติทั้งหมด
4. กด **เข้าสู่ระบบรายงานจริง** แล้วใช้บัญชี Pilot ที่ได้รับจากผู้ดูแล
5. เลือกรายงานจากรายการที่บัญชีเปิดได้

## ถ้าล็อกอินแล้วเจอหน้าว่าง

ไม่ต้องกดเมนูเทคนิคและไม่ต้องลองสร้างข้อมูลเอง รายการว่างมักหมายถึงอย่างใด
อย่างหนึ่ง:

- ยังไม่มีรายงานที่ประกาศพร้อมใช้ในรอบ Pilot
- บัญชีของคุณยังไม่ได้รับสิทธิ์รายงานนั้น
- รายงานอยู่ระหว่างตรวจคุณภาพหรือรอเจ้าของข้อมูลอนุมัติ

ให้กลับมาที่ PSU Data Hub แล้วคัดลอกรูปแบบคำขอใช้ข้อมูล โดยระบุคำถามที่
ต้องการตอบ วัตถุประสงค์ ช่วงข้อมูล หน่วยงานเจ้าของ และวันที่ต้องใช้

## เรื่องที่ต้องจำ

- อย่าส่งรหัสผ่าน คีย์ระบบ หรือข้อมูลส่วนบุคคลผ่านแชตและอีเมล
- อย่าคิดว่าการเลือก “นักวิเคราะห์” หรือ “ทีมแพลตฟอร์ม” บนหน้าแรกทำให้ได้
  สิทธิ์เพิ่ม สิทธิ์จริงตรวจจากบัญชีและนโยบายข้อมูลทุกครั้ง
- รุ่น Pilot ยังล็อกอินหน้ารายงานอีกหนึ่งครั้ง เมื่อเชื่อม PSU SSO แล้วจึงจะ
  เหลือการล็อกอินครั้งเดียว
- ถ้าระบบรายงานขึ้นว่าไม่ตอบสนอง ให้จดเวลาที่พบปัญหาและส่งภาพหน้าจอที่ไม่มี
  รหัสผ่านให้ทีมข้อมูล

## สำหรับเจ้าของข้อมูล

ก่อนส่งข้อมูลให้ทีมแพลตฟอร์ม เตรียมอย่างน้อย:

1. ชื่อชุดข้อมูลและผู้รับผิดชอบ
2. วัตถุประสงค์และผู้ใช้ปลายทาง
3. ความถี่และเวลาที่ต้องปรับปรุง
4. คำอธิบายคอลัมน์สำคัญ
5. ระดับความอ่อนไหวและฐานการใช้ข้อมูล
6. ข้อมูลส่วนบุคคลที่สามารถตัดออกได้

อย่าส่งไฟล์จริงจนกว่าจะตกลงพื้นที่รับส่ง ผู้รับผิดชอบ และผู้อนุมัติแล้ว
